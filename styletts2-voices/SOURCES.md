# StyleTTS2 reference voices

Short reference clips used to derive StyleTTS2 style embeddings (the model
clones the narrator from a reference). Downloaded from the official StyleTTS2
demo page, `https://styletts2.github.io/wavs/LibriTTS/Ref/`:

- `1221-135767-0014.wav`, `4077-13754-0000.wav`, `5639-40744-0020.wav`, `908-157963-0027.wav`
- `3.wav`, `4.wav`, `5.wav`

Reference audio originates from LibriTTS (LibriSpeech), licensed CC BY 4.0.
They are 3 s, 16 kHz mono clips; the app never plays them, it only uses their
style embedding.
